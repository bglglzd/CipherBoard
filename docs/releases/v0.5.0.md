## Offline Voice Typing

The toolbar microphone now recognizes Russian and English entirely inside
CipherBoard. The active keyboard layout selects the matching checksum-pinned
Vosk model. Both models are already in the APK; the installed keyboard has no
Internet or network-state permission and performs no runtime model download.

Android asks for microphone access on first use. CipherBoard captures audio
only during the explicit session, keeps recognition in memory, creates no audio
file, and stops on a second microphone tap or after 60 seconds. The first use
of each language can take a few seconds while its packaged model is copied to
private no-backup storage. Voice input is unavailable in passwords, email
fields, and every CipherBoard-owned editor, including Private mode.

## Russian and English Gesture Typing

The normal keyboard can now import the compatible gesture library through
**CipherBoard settings → Advanced → Load gesture typing library**. CipherBoard
accepts only the exact ABI-specific SHA-256 pinned in source, stores the result
privately, and rechecks it before every load. The installed library survives an
in-place CipherBoard update.

The gesture library is proprietary and is not redistributed in the APK.
Installing it expands the native code trusted inside the keyboard process;
unknown or modified files are rejected with no override.

## Updates and Compatibility

This release does not change identities, pairing, Olm sessions, message
envelopes, or Compact/Russian-word/English-word presentations. It uses the same
package name and signing certificate so Android and Obtainium can install it
over an existing release. CipherBoard itself remains offline; configured
automatic update checks and downloads are performed by Obtainium as a separate
networked installer.

CipherBoard uses reviewed cryptographic primitives and automated tests, but the
complete product has not received an independent applied-cryptography and
Android security audit.
