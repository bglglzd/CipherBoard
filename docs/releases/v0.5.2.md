# CipherBoard 0.5.2

## Download

[**Download CipherBoard-0.5.2-release.apk**](https://github.com/bglglzd/CipherBoard/releases/download/v0.5.2/CipherBoard-0.5.2-release.apk)

Install this APK over the existing CipherBoard app. Do not uninstall or clear
app data: doing so destroys the local identity, contacts, and ratchet state.
The `.sha256` attachment verifies the APK; the verification ZIP contains the
exact-source, build, license, SBOM, and vulnerability-scan evidence.

## Quieter Offline Dictation

Starting and completing offline dictation no longer creates a separate gray
Android banner. Preparation, listening, live recognition, and processing remain
visible in the dedicated keyboard-height voice panel. Successful insertion,
an empty result, and cancellation now finish quietly without a Toast.

Actual failures remain visible: CipherBoard still reports a missing microphone
permission, a microphone startup failure, or a packaged-model loading failure.

## Privacy and Compatibility

This release does not change speech recognition. Russian and English audio is
still processed entirely on device with packaged, checksum-pinned Vosk models;
audio and transcripts are not logged or persisted. CipherBoard still has no
Internet or network-state permission, and voice input remains blocked in
passwords, email fields, Private mode, and all CipherBoard-owned editors.

The package name and signing certificate are unchanged, so Android and
Obtainium can update an existing installation in place.
