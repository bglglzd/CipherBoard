# CipherBoard 0.5.1

## Download

[**Download CipherBoard-0.5.1-release.apk**](https://github.com/bglglzd/CipherBoard/releases/download/v0.5.1/CipherBoard-0.5.1-release.apk)

Install this APK over the existing CipherBoard app. Do not uninstall or clear
app data: doing so destroys the local identity, contacts, and ratchet state.
The `.sha256` attachment verifies the APK; the verification ZIP contains the
exact-source, build, license, SBOM, and vulnerability-scan evidence.

## Clearer Offline Dictation

Tapping the toolbar microphone now replaces only the keyboard area with a
dedicated dictation panel. A large pulsing microphone and **Listening** state
make it clear when audio capture is active, while recognized words appear as a
live partial transcript. Preparation and final processing have separate states.

After Vosk detects trailing silence, CipherBoard keeps a short continuation
window and then finishes recognition and inserts the text automatically. If
speech resumes during that window, automatic finishing is postponed. The large
microphone remains available for manual finishing, and the existing 60-second
limit remains a hard fallback.

Russian and English continue to use the model selected by the active keyboard
layout. The first use of either model may take a few seconds while CipherBoard
copies its packaged assets into app-private no-backup storage.

## Privacy and Compatibility

Dictation still runs entirely inside CipherBoard using the packaged,
checksum-pinned Vosk models. Audio and transcripts are not logged or persisted,
and the app has no Internet or network-state permission. Voice remains blocked
in passwords, email fields, Private mode, and all CipherBoard-owned editors.

This update does not change identities, pairing, Olm sessions, message
envelopes, or ciphertext presentations. It keeps the same package name and
signing certificate, so Android and Obtainium can update an existing install in
place.
